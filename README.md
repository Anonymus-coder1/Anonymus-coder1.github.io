# 🔐 Password Strength Tester

A modern and interactive password strength analyzer built with HTML, CSS, and JavaScript.

This tool evaluates password security based on multiple factors including length, character diversity, entropy, and pattern detection. It provides real-time feedback and an estimated cracking time to help users understand how secure their passwords are.

Designed for educational purposes, this project demonstrates how password strength can be analyzed locally in a browser environment without sending any data externally.
# 📖 Usage

1. Open the application in your browser.
2. Enter a password in the input field.
3. The tool will instantly analyze your password and display:
   - A strength indicator (Weak → Very Strong)
   - A visual progress bar
   - An estimated cracking time
4. Improve your password based on the feedback provided.

💡 Tips

- Use at least 12 characters
- Mix uppercase, lowercase, numbers, and symbols
- Avoid common patterns like "123456" or "qwerty"
- Prefer long passphrases over short complex passwords
